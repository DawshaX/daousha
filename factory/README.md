# 🏭 مصنع XDAW NOVA v2 — الدليل الرئيسي

> **المالك:** دوشة (Dawsha) | **الهوية:** نور • معرفة • رحمة • قوة مسؤولة
> **الهدف:** مصنع يعمل 24/7 — ينتج مخزون سنة إلى 3 سنين — وينشر **فيديو كل ساعة** على كل المنصات.

## 🧠 الفكرة في 30 ثانية

```
المواضيع (بنك 1000+) → سيناريو AR+EN → تعليق صوتي → 4 مشاهد بهوية NOVA
→ تجميع + شعار + ترجمة → فحص جودة → 🏦 المخزون (Vault)
→ ⏰ محرك النشر كل ساعة (بالتناوب على المنصات) → 📢 تلجرام
```

**القاعدة الذهبية:** الإنتاج يسبق النشر دائماً. النشر يسحب من المخزون فقط —
لو توقف الإنتاج أسبوع، النشر كل ساعة يستمر عادي من المخزون.

## 📁 هيكل المصنع

```
factory/
├── config/         factory.json (التشغيل) + brand.json (الهوية)
├── brand/          الشعار والغلاف الأصليين (ارفع ملفاتك هنا)
├── topics/         بنك المواضيع (seed اليدوي + bank_full المولّد)
├── pipeline/       خط الإنتاج: 01 مواضيع → 09 جدولة
├── state/          حالة المصنع (مُتجاهلة من Git)
├── vault/          🏦 مخزون الفيديوهات الجاهزة (مُتجاهل من Git)
├── output/         مخرجات الإنتاج اليومي (مُتجاهلة من Git)
├── tests/          اختبارات بلا إنترنت
└── ops/            تشغيل 24/7 (systemd + cron)
```

## 🚀 التشغيل السريع

```bash
cd factory
pip install -r requirements.txt
cp .env.example .env   # ثم املأ الأسرار

# 1) أنتج حلقة واحدة (عربي + إنجليزي)
python3 -m pipeline.make_episode --lang both

# 2) افحص المخزون
python3 -m pipeline.vault --status

# 3) شغّل محرك النشر كل ساعة (يستمر للأبد)
python3 -m pipeline.scheduler --every-minutes 60
```

## 🛡️ قواعد ملزمة (من دروس v1)

1. **لا أسرار في Git أبداً** — كلها في `.env` فقط.
2. **لا فيديوهات في Git** — المخزون والمخرجات مُتجاهلة.
3. **لا نشر بلا مخزون احتياطي 72 ساعة على الأقل.**
4. **لا منصتين في نفس الدقيقة** — فاصل زمني بين المنصات.
5. **الجودة قبل الكمية** — أي فيديو يفشل QC لا يُنشر أبداً.
6. **عند 3 أخطاء متتالية:** توقف + تلجرام لدوشة فوراً.
