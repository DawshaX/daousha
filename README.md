## ما الذي يفعله النظام كل دورة؟

1. **يختار الحلقة التالية** من مكتبة المواضيع (لا يكرر منشورًا أبدًا)
2. **يكتب/يجهّز السيناريو** (عربي + إنجليزي) — من البنك الجاهز أو LLM مجاني
3. **دوشة تسرد الحكاية** بصوتها الأنثوي المصري المميز (ar-EG-Salma — مجاني بلا حدود)
4. **يبني المشاهد بهوية القناع**: القناع النيوني الرسمي يفتتح ويختم كل حلقة، وكل حقيقة ليها أيقونة نيون رمزية ترسم كلماتها (قلب، برق، DNA، صاروخ… 22 رمزًا) — أو لقطات Pexels حقيقية إن أضفت مفتاحها
5. **المونتاج السينمائي 2099**: خلفيات حية مولّدة رياضيًا (سدم بلازما + مدن 2099 بنوافذها المضيئة + شبكات أحلام — لا تتكرر أبدًا) + تنفّس كاميرا + ميلان سينمائي + جزيئات ضوئية عائمة + كينيتيك كابشنز كاريوكي بتلوين الكلمات المفتاحية + فلاش درامي عند الفواصل + whoosh صوتي + موسيقى 2099 ويف بنبض سايد تشين + القناع علامة مائية دائمة + غلاف PNG رسمي لكل حلقة
6. **ينشر** على YouTube Shorts + Facebook Reels + Instagram Reels (+TikTok عند القبول)
7. **يرسل تقرير تلجرام** بكل الروابط وحالة النظام
8. **يحدّث المستودع** (الحالة + لوحة المتابعة `dashboard/status.html`) ويلتزم سقف النشر الآمن

## التشغيل في 3 خطوات (مجاني 100%)

### الخطوة 1 — ارفع هذا المجلد إلى مستودع GitHub **عام** (Public)
عام لسببين: Actions مجاني بلا حدود، وإنستجرام يحتاج رابطًا عامًا لملف الفيديو (يُرفع تلقائيًا كـ Release).

### الخطوة 2 — أضف ما تملكه من مفاتيح في: Settings → Secrets and variables → Actions
| المفتاح | من أين | ضروري؟ |
|---|---|---|
| `YOUTUBE_CLIENT_ID` / `YOUTUBE_CLIENT_SECRET` / `YOUTUBE_REFRESH_TOKEN` | Google Cloud → YouTube Data API v3 (راجع `docs/setup-keys.md`) | اختياري |
| `FACEBOOK_PAGE_ID` / `FACEBOOK_PAGE_ACCESS_TOKEN` | Meta for Developers (token صفحة دائم) | اختياري |
| `INSTAGRAM_USER_ID` / `INSTAGRAM_ACCESS_TOKEN` | حساب IG تجاري مرتبط بالصفحة | اختياري |
| `TELEGRAM_BOT_TOKEN` / `TELEGRAM_CHAT_ID` | @BotFather | اختياري |
| `PEXELS_API_KEY` | pexels.com/api (مجاني) | اختياري |
| `LLM_API_BASE` / `LLM_API_KEY` / `LLM_MODEL` | Groq مجاني | اختياري |

> **لا مفاتيح على الإطلاق؟** النظام يشتغل كاملًا: ينتج الحلقات ويخزنها كـ Artifacts ويبني لوحة المتابعة، ويطبع ما ينقصه للنشر. أضف أي مفتاح متى تيسّر وستنشر فورًا.

### الخطوة 3 — فعّل الجدولة
الجدول مضمّن: `.github/workflows/nova.yml` يعمل **كل ساعة** تلقائيًا.
- ضوابط الأمان مفعّلة افتراضيًا: سقف 4 حلقات/يوم يرتفع تلقائيًا مع سلسلة النجاح (4→6→8→12→16) وفارق ≥4 ساعات لكل منصة — لأن المنصات تظلم الحسابات التي تغرقها منشورات (الوثيقة القديمة نفسها أوصت بذلك).
- تريد النشر الفعلي كل ساعة (24/يوم)؟ أضف Secret باسم `NOVA_DAILY_CAP=24` و`NOVA_PLATFORM_GAP_H=1` — على مسؤوليتك من حظر الخوارزميات.

### تشغيل محلي/VPS بدلًا من GitHub (اختياري)


## بنية المستودع
```
nova/                 محرك النظام (Python فقط — بلا أي خدمات مدفوعة)
  run_cycle.py        قائد الدورة: إنتاج → نشر → إشعار → تحديث حالة
  content.py          بنك المواضيع والسيناريوهات + المولّد اللانهائي
  tts.py              التعليق الصوتي (edge-tts) + توقيتات كلمة-بكلمة
  scenes.py           مشاهد Pexels أو مولّدة برمجيًا (هوية العلامة)
  video.py            مونتاج ffmpeg: Ken Burns + انتقالات + كابتشنز + موسيقى
  publish/            يوتيوب، فيسبوك، إنستجرام، تيك توك
content/topics.json   40+ حلقة بحالاتها (منقولة من النظام القديم بالكامل)
dashboard/status.html لوحة متابعة عربية تُحدَّث تلقائيًا (GitHub Pages جاهزة)
.github/workflows/    الجدولة الساعية المجانية
docs/setup-keys.md    شرح مصور خطوة-بخطوة لكل مفتاح
```

## قواعد النظام (موروثة من النسخة القديمة + محسّنة)
