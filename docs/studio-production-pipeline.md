# خط إنتاج الاستوديو

يدير الاستوديو مراحل إنتاج الفيديو الأصلية من الفكرة إلى مادة قابلة للمراجعة، مع فصل صريح بين ما ينشئه النظام نصيًا أو بصريًا وما يحتاج قرارًا بشريًا أو أداة تسجيل خارجية.

| المرحلة | المكوّن | الناتج المحكوم |
|---|---|---|
| الفكرة والموجز | استوديو المشروع | مشروع تشغيلي أو حزمة Short + Long |
| السكربت | مولد السكربت | نسختان عربية وإنجليزية، مع خطاف وملاحظات حقوق وسلامة |
| التعليق والترجمة | بطاقتا السكربت | نص التعليق ونص الترجمة/النص المصاحب لكل لغة للمراجعة |
| اللقطات والمواد المساندة | معمل المشاهد | مشهد رئيسي أو B-roll أو غلاف أصلي |
| الحقوق والسلامة | بوابة المراجعة | مادة تحتاج قرارًا بشريًا قبل أي استخدام أو نشر |

> لا يولد الاستوديو ملفًا صوتيًا ولا فيديو نهائيًا تلقائيًا. يمثل التعليق في المرحلة الحالية نصًا قابلاً للتسجيل والمراجعة، وتبقى كل خطوة نشر خلف الحواجز والتأكيدات المعتمدة.
