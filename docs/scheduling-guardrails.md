# حراسة الجدولة

لا تقبل XDAW NOVA الآن إنشاء مسودة جدولة أو تفعيلها إلا لقناة **YouTube** المفوضة رسميًا والمزودة ببيانات اعتماد خادمية صالحة. لا يظهر في الواجهة حقل منصة حر، ولا يُنشأ أي تشغيل دوري لمنصة لم تصبح جاهزة.

إذا فقدت القناة تفويضها بعد إنشاء مسودة قائمة، تتحول المسودة إلى `needs_approval` وتسجل المنصة محاولة إشعار. وعند التنفيذ، يوقف أي حاجز حقوق أو سلامة أو معاينة الجدولة نفسها قبل تكرار العملية.

> TikTok وFacebook وInstagram تبقى خارج الجدولة الدورية: TikTok ينتظر الموافقة وتفويض الإنتاج، Facebook ينتظر OAuth الدائم، وInstagram يتطلب تأكيدًا منفصلًا لكل Reel.
