# حزم الإنتاج القصيرة والطويلة

تبدأ الحزمة بفكرة أم `package_parent` تمثل الموجز المشترك فقط. تنشئ المنصة تحتها نسختين منفصلتين: **Short/Reel عمودية** (`vertical`) و**Long Form أفقية** (`horizontal`). لكل نسخة حالة إنتاج ومراجعة وأصول ولقطات أداء مستقلة.

| الكيان | الغرض | يدخل الإنتاج أو الجدولة؟ |
|---|---|---|
| الفكرة الأم | تجميع الموجز والعلاقة | لا |
| النسخة العمودية | Short / Reel | نعم، بعد الحواجز والمراجعة |
| النسخة الأفقية | Long Form | نعم، بعد الحواجز والمراجعة |

تستبعد الحراسة الخادمية الفكرة الأم من مولد السكربت، ومعمل المشاهد، وربط الأصول، والمراجعة، والجدولة، والنشر، ولقطات الأداء. تستخدم الواجهات التشغيلية قائمة نسخ فقط؛ لذا لا تدخل الحاوية في الأهداف أو التحليلات أو قوائم النشر حتى لو وُجدت ضمن قائمة الاستوديو.

## تحقق النسخة

أصبح استبعاد الحاوية خادميًا في قائمة علاقات مشروع-فيديو التي تغذي توازن المحتوى اليومي ومكتب النشر، وليس مجرد ترشيح في الواجهة. وتغطي اختبارات الإجراءات انتقال المراجعة، والجدولة، وتسجيل لقطة الأداء، وقائمة المشاريع التشغيلية، ومؤشرات توازن المحتوى ببيانات حزمة تتضمن حاوية ونسختين. نجحت مجموعة الانحدار الكاملة في **55 اختبارًا ضمن 35 ملفًا** بعد هذه الإضافة.
