# قياس أداء XDAW NOVA

تستمد شاشة التحليلات أرقامها من **لقطات أداء موثقة** فقط. لكل نطاق `منصة + مشروع` تستخدم المنصة أحدث لقطة لتفادي جمع القراءات التراكمية مرتين، وتعرض المسار الزمني للقطات الفعلية دون أعمدة أو قيم اصطناعية عند غياب البيانات.

| المؤشر | طريقة الحساب | القيد |
|---|---|---|
| المشاهدات الحالية | مجموع أحدث لقطة لكل منصة/مشروع | لا تُنشأ قيم عند عدم وجود لقطة |
| نسبة التفاعل | إجمالي التفاعلات ÷ إجمالي المشاهدات | مؤشر وصفي، لا يتنبأ بالأداء |
| متوسط الاحتفاظ | متوسط قيم الاحتفاظ في أحدث اللقطات | لا يساوي جودة المحتوى أو ضمان الانتشار |

توصية الاختبار تقترح تغييرًا واحدًا قابلًا للقياس بحسب الاحتفاظ والتفاعل. لا تعد هذه التوصية بالمشاهدات أو الدخل ولا تغير استراتيجية النشر تلقائيًا.

تُصنّف اللقطة الجديدة أيضًا على أنها عربية أو إنجليزية أو حزمة ثنائية أو غير مصنفة. تعرض لوحة الرؤى تفصيلًا منفصلًا لأحدث قراءة موثقة لكل `منصة + مشروع`، وتفصيلًا آخر للنسخ بحسب هذا التصنيف. تُحفظ اللقطات القديمة باعتبارها **غير مصنفة** ولا تُنسب إلى لغة من دون دليل.
