# مسار الإنتاج الأصلي والمرخّص في XDAW NOVA

## الهدف

يتحول كل موضوع إلى مشروع تشغيلي قابل للمراجعة من دون تنزيل أو إعادة استعمال مادة لا يثبت ترخيصها. لا يصبح المشروع قابلاً للنشر لمجرد وجود فكرة أو سكربت أو رابط إلهام.

| المرحلة | ما ينفذه NOVA | الحالة المطلوبة للانتقال |
|---|---|---|
| الموجز | إنشاء مشروع أو حزمة لغوية/صيغة مناسبة | عنوان وموجز واضحان |
| السكربت | إنشاء مسودة عربية وإنجليزية أصلية | مراجعة بشرية للنص والمعلومات |
| المشهد | توليد مشهد أصلي أو تسجيل مادة مرخصة | رابط الأصل والترخيص ونوع الترخيص عند وجود مادة خارجية |
| الحزمة | ربط المادة بالمشروع ودورها: أساسية أو B-roll أو صوت أو مرجع | لا يتغير اعتماد الحقوق أو السلامة بسبب الربط |
| المراجعة | قرار حقوق وسلامة، وإقرار معاينة للمشروع | فيديو مرتبط مع حقوق `approved` وسلامة `clear` |
| الإرسال | فحص Canary والسياسة والقناة قبل الرفع | لا يتم النشر إلا بعد الحواجز والوجهة المفوضة |

## أصول مرئية مسموحة

تُستخدم المشاهد المولدة أصليًا أو اللقطات التي تسجل لها صفحة الأصل وصفحة الترخيص ونوع الترخيص. تعالج المواد كـ`pending` أو `held` حتى يراجعها إنسان مخول. لا تغير عمليات القص أو تحسين اللون أو تركيب النص أو شعار XDAW NOVA حالة الحق القانوني للمادة.

## حالة فيديوهات جديدة

لا يمكن إكمال فيديو جديد قابل للنشر عند غياب ملف فيديو أصلي أو مرخص ومقبول في بوابة الحقوق، أو عند بلوغ حصة توليد الفيديو. يبقى النظام قادرًا على تجهيز الموجز والسكربت والمشاهد الثابتة والبيانات الوصفية وحزمة المراجعة، لكنه لا يدعي وجود فيديو أو نشر لم يحدث.
