# حالة رمز صفحة Facebook

في فحص التكامل الخارجي بتاريخ 15 أغسطس 2026، أعادت Meta `401 / OAuthException 190 / subcode 467` لرمز الصفحة الحالي. تصنف المنصة هذه النتيجة الآن كـ **رمز منتهٍ أو ملغى**، ولا تحاول رفع أي فيديو عند ظهورها.

| نوع الفشل | الحالة الظاهرة | السلوك |
|---|---|---|
| `190` مع `463` أو `467`، أو `401` | `expired_or_revoked` | إيقاف الرفع وطلب تجديد التفويض الرسمي |
| `403` | `mismatch` | إيقاف الرفع والتنبيه إلى عدم تطابق صلاحيات الصفحة |
| فشل شبكة أو `5xx` | `unreachable` | لا رفع ولا إعادة محاولة صامتة |

فحص التكامل الحي أصبح اختياريًا عبر `RUN_LIVE_PLATFORM_TESTS=true`؛ بينما تبقى اختبارات تصنيف الحالات مستقرة ضمن الانحدار العادي. لا يعرض التشخيص رمز الوصول أو يطبعه.
