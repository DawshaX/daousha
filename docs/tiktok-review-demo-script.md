# XDAW NOVA — TikTok Review Demo Script

هذا الفيديو المبدئي يستخدم لقطات حقيقية من واجهة XDAW NOVA ولا يعرض حساب TikTok مفوضًا أو نشرًا فعليًا قبل اعتماد التطبيق. مدته 36 ثانية، ويعرض فقط ما هو موجود فعليًا: مركز القنوات، بوابات الحقوق والمعاينة والموافقة البشرية، ومركز التحكم.

| الزمن | اللقطة الحقيقية | النص المعروض للمراجع |
|---:|---|---|
| 00:00–00:12 | صفحة الإعدادات ومركز القنوات | `1. TikTok Login Kit starts from XDAW NOVA Settings. Tokens remain server-side.` |
| 00:12–00:24 | بوابة المراجعة | `2. Original content passes rights, safety, preview, and human-confirmation gates.` |
| 00:24–00:36 | غرفة التحكم | `3. Content Posting API uploads a draft or Direct Posts only after the owner confirms.` |

> **حد الاستخدام:** لا يُقدَّم هذا الفيديو على أنه إثبات نجاح OAuth أو النشر في الإنتاج. بعد حفظ المسودة، يجب تسجيل نسخة نهائية من البيئة Sandbox تُظهر دخول TikTok الفعلي وعودة OAuth وحالة رفع محتوى أصلي اختباري قبل الضغط على `Submit for review`.
