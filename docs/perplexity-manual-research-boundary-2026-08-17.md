# حدود استخدام Perplexity في XDAW NOVA

## القرار التشغيلي

بناءً على قرار المالك في 17 أغسطس 2026، **لن يُفعَّل Perplexity API** في XDAW NOVA ما دام الحساب يحتاج رصيد API مدفوعًا. لا يُستخدم المفتاح المخزن، ولا يوجد أي مسار خادمي أو مهمة مجدولة تعتمد عليه.

## الاستخدام المسموح

يمكن للمالك استخدام موقع Perplexity العادي في متصفحه بصفة يدوية للبحث أو النقاش. عند وجود نتيجة مفيدة، تُحفظ داخل NOVA كـ **نتيجة قراءة موثقة** تشمل عنوانًا وملخصًا ورابط المصدر الأصلي، ثم تخضع لمراجعة الحقوق قبل أن تؤثر في مشروع محتوى.

## الاستخدام المحظور

لا يحوّل NOVA جلسة تسجيل الدخول العادية، أو ملفات تعريف الارتباط، أو واجهة الدردشة الاستهلاكية إلى واجهة API خلفية. ولا ينفذ تسجيل دخول تلقائيًا، أو محادثات آلية، أو نسخ محتوى، أو تنزيل وسائط عبر الموقع. لا تمنح نتيجة البحث حق استخدام أي مادة خارج شروط ترخيصها.

## البدائل المتاحة

تظل بوابة NOVA قادرة على فتح المصادر المرخصة المسجلة يدويًا، مثل Pexels وPixabay وMixkit، ثم توثيق المصدر والترخيص لكل مادة قبل الإنتاج. ويبقى Gemini وOpenAI موقوفين عن الاستدعاء إلى حين اكتمال اختبار مفاتيحهما وربطهما في مسار خادمي منفصل.
