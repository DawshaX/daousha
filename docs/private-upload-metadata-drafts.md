# مسودات بيانات الرفع الخاصة

تفصل XDAW NOVA بين **صياغة بيانات الرفع** وبين **طلب الرفع**. تحفظ المسودة عنوان الفيديو ووصفه ووسومه ضمن خصوصية `private` وداخل ملكية المستخدم نفسه، ولا تنتج سجل نشر أو فحص حواجز أو اتصالًا خارجيًا.

| الإجراء | شرطه | النتيجة |
|---|---|---|
| حفظ مسودة | فيديو مرتبط بمشروع مملوك | تحديث عنوان ووصف ووسوم YouTube الخاصة فقط |
| فحص الحواجز | إقرار معاينة ومادة صالحة | لا يحدث إلا بزر منفصل |
| رفع نسخة خاصة | قرار الحارس الخاص | لا يحدث إلا بزر منفصل بعد الفحص |
| نشر عام | تأكيد نصي صريح | لا يظهر إلا بعد استيفاء الحواجز |

تغطي اختبارات الإجراء رفض فيديو غير مرتبط وعدم إنشاء `publishing_run` عند حفظ المسودة. كما تحققت صفحة المراجعة على سطح المكتب والهاتف؛ وعند غياب فيديو قابل للمراجعة تعرض حالة فارغة ولا تدعي وجود رفع أو نشر.
