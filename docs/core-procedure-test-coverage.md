# تغطية اختبارات الإجراءات الأساسية

تغطي اختبارات إجراءات XDAW NOVA الأساسية الآن المالك الموثق وتدفق المراجعة بدل التحقق من واجهات سطحية فقط.

| المجال | ما يثبته الاختبار |
|---|---|
| المشروع | إنشاء مشروع تحت مالك الجلسة |
| المصدر | إنشاء المصدر بحالة `proposed` ثم قرار مراجعة مسجل في سجل التغييرات |
| المادة | التسجيل عبر بوابة الحقوق، والتنبيه للمراجعة، وقرار حقوق/سلامة مسجل |
| الرفع | رفض تجاوز 10 ميجابايت قبل التخزين وعدم إنشاء مادة عند فشل التخزين |
| الجدولة | إنشاء مسودة لنُسخة تشغيلية على YouTube المفوض ورفض الفكرة الأم |
| التغييرات | حفظ قرارات مراجعة المصدر والمادة كأحداث قابلة للتدقيق |

تبقى تغطية فشل مزودات توليد الذكاء الاصطناعي بندًا منفصلًا، لأنها تتطلب اختبارًا مخصصًا لمسار المولد البصري أو النصي دون استدعاء خارجي فعلي.
