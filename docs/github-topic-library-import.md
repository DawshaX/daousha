# استيراد مكتبة موضوعات GitHub

أضيفت لقطة مراجعة من `scripts/topic_library.json` في مستودع `DawshaX/daousha`. تضم اللقطة **21 فكرة غير منشورة** من المصدر، فيما استُبعدت الحلقات التي وُسمت في المصدر بأنها منشورة حتى لا تُعامل كأفكار جديدة.

| خطوة المستخدم | ما يحدث | ما لا يحدث |
|---|---|---|
| البحث في المكتبة | ترشيح العناوين والزوايا داخل الاستوديو | لا طلب شبكي ولا تعديل للمستودع |
| اختيار فكرة | يملأ العنوان والموجز بملاحظة تحقق حقائق ومصادر | لا إنشاء مشروع ولا أصل ولا جدولة |
| إنشاء المشروع | يتطلب ضغط المستخدم على زر الإنشاء المعتاد | لا نشر على أي منصة |

تؤكد الاختبارات أن اللقطة تستبعد الحلقات المنشورة وأن الموجز يطلب التحقق من الحقائق والمصادر قبل إنشاء مشروع أو نشر. تحققت واجهة المكتبة على سطح المكتب والهاتف، وتبقى بطاقة المصدر رابطًا مرجعيًا فقط.
