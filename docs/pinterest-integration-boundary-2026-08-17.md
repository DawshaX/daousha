# حدود تكامل Pinterest في XDAW NOVA

## الغرض المسموح

يقتصر Pinterest داخل XDAW NOVA، عند إنشاء تطبيق رسمي وتفويض المالك، على **البحث المرجعي والإلهام البصري** وقراءة Pins والحساب أو اللوحات التي يفوضها المالك. تدعم وثائق Pinterest REST API البحث في Pins عبر OAuth 2.0 وبنطاقات قراءة مثل `pins:read` و`boards:read`.[1]

## حدود لا تتغير

لا يُعامل أي Pin أو صورة أو فيديو في Pinterest على أنه مادة مرخصة للإنتاج أو ملكية خاصة لـXDAW NOVA. لا ينزّل النظام وسائط Pinterest، ولا يزيل علامة مائية، ولا يغطي أو يعدّل محتوى Pinterest، ولا ينشئ عملاً موزعًا مشتقًا من Pins. تشترط إرشادات Pinterest أيضًا الإسناد والرابط الواضح إلى المصدر عند عرض محتواها، وتحظر الأتمتة أو الاستخراج غير المصرح به.[2]

لا يخزن NOVA بيانات Pinterest المسترجعة، ولا يجمع بيانات الحسابات، ولا ينفذ أي نشر أو حفظ Pin آليًا. أي تكامل رسمي لاحق يحتاج تطبيق Pinterest، وتفويض OAuth من المالك، وموافقة صريحة منفصلة قبل تشغيله.

## مسار الإنتاج البديل

للمقاطع المنشورة، يستخدم NOVA لقطات أصلية أو موادًا مرخصة صراحةً لكل أصل، مثل مصادر اللقطات المسجلة للمراجعة في البرنامج. يبقى لكل لقطة سجل مصدر وترخيص وقرار حقوق وسلامة مستقل قبل الإنتاج أو النشر.
