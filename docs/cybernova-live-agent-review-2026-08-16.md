# مراجعة مرجعية: CyberNova Live Agent

## نطاق المراجعة

فُهرس الأرشيف `Hello-Peace.rar` واستُخرجت للقراءة فقط الملفات التالية: `LiveAgentPanel.tsx` و`NovaAgentChat.tsx` وصفحات الوكيل القريبة وملف التهيئة. لم يُشغّل أي كود من الأرشيف، ولم تُثبّت حزم المشروع أو تُستورد أسراره أو تُشغّل خدماته.

## ما يصلح كنمط تصميم للمساعد الموحد

| العنصر | الفائدة لـXDAW NOVA | قرار التصميم |
|---|---|---|
| سجل جلسات محادثة | يحتفظ بسياق المستخدم ومهام المحتوى السابقة | يعتمد بعد ربطه بمالك الحساب وسجل تدقيق |
| وضع «خطط أولًا» | يعرض خطة قابلة للتعديل ثم ينتظر قرار المستخدم | يعتمد للأعمال متعددة الخطوات والتأثير العالي |
| بطاقات تنفيذ الأدوات | توضح ما يفعله المساعد ونتيجته بدل تنفيذ غامض | يعتمد، لكن بأدوات المحتوى والقنوات فقط |
| مرفقات الجلسة | تسمح بربط موجز أو نص أو فيديو بمشروع محتوى | يعتمد مع تخزين S3 وفحص نوع وحجم الملف |
| شريط حالة المحرك | يعرض حالة المساعد، القنوات، والمهام | يعتمد بصياغة XDAW NOVA |
| وضع صوتي وواجهة مرنة | تحسين اختياري لتجربة الاستخدام لاحقًا | يؤجل للمرحلة الثانية |

## ما يجب إعادة بنائه لا نسخه

| العنصر المرجعي | سبب عدم النسخ المباشر | البديل في XDAW NOVA |
|---|---|---|
| مزود Ollama محلي ونداء المتصفح المباشر | لا يتوافق مع استضافة المشروع وإدارة الأسرار | استدعاء خادمي لمزود الذكاء الاصطناعي مع سجل استخدام وحدود واضحة |
| مسارات `/api/live-agent/*` الخاصة بالمشروع المرجعي | عقود بيانات وأمن مختلفة | واجهات tRPC مخصصة للمساعد وسجل الأوامر |
| بث التفكير الخام | لا يضيف قرارًا تنفيذيًا موثوقًا وقد يربك المستخدم | حالة مختصرة: «يفهم» و«يخطط» و«ينفذ» مع خطة ونتائج مدققة |
| التنفيذ المختلط من المتصفح والخادم | يزيد السطح الهجومي ويصعب التدقيق | منفذ أوامر خادمي واحد مسجل ومقيد بالصلاحيات |

## ما يستبعد نهائيًا

لا ينتقل أي زر أو أداة مرتبطة بالاستطلاع الشبكي أو اختبار الاختراق أو الطرفية أو الفحص أو البحث عن الاستغلالات أو أوامر النظام. هذه ليست جزءًا من هدف XDAW NOVA الخاص بإدارة المحتوى، كما أنها توسع الصلاحيات دون حاجة تشغيلية.

## نموذج المساعد المقترح

يضم المساعد الموحد ثلاث طبقات في واجهة واحدة: **فهم المحادثة** لتحويل الكلام الطبيعي إلى نية، و**منفذ أدوات محتوى مقيد** لإنشاء المسودات والجدولات وقراءة الحالة، و**مستشار استباقي** يقترح الخطوة التالية اعتمادًا على حالة المشروع. يستقبل الواجهة الداخلية وTelegram الرسائل عبر نفس المنفذ، مع ربط كل رسالة بمالك موثق وسجل أوامر واحد.

لا ينفذ النشر العام أو الحذف أو تعديل مفتاح الإيقاف أو تبديل القنوات بمجرد تفسير لغوي؛ يعرض ملخص أثر واضح ثم يتطلب اعتمادًا صريحًا داخل نفس المحادثة.
