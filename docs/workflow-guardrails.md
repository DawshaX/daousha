# حراسة سير عمل XDAW NOVA

يحفظ المشروع مراحل واضحة من `idea` إلى `research` و`script` و`production` ثم `review` و`approved`. لا يسمح الخادم بتجاوز المراجعة إلى الاعتماد، ويسمح فقط بالعودة الصريحة إلى الإنتاج عند اكتشاف حاجة إلى تعديل. تظل حالة `blocked` مسار توقف قابلًا للإصلاح ولا تفتح النشر.

> الاعتماد البشري لا يتاح إلا بعد وجود أصل فيديو مرتبط بالمشروع نفسه، وبحالة **حقوق معتمدة** و**سلامة واضحة**. لا يكفي وجود مادة مستقلة في المكتبة أو صورة مولدة أو حالة مراجعة معلقة.

تعمل هذه الحراسة على الخادم قبل تغيير الحالة، لذلك لا يمكن تجاوزها من واجهة العميل أو من مهمة دورية. ويبقى النشر العام محكومًا بحواجز إضافية: إقرار المعاينة، سياسة النشر، اتصال القناة، والموافقة المطلوبة لكل منصة.

## بوابة الحقوق والسلامة عند الاستقبال

تمر كل مادة جديدة عبر تقييم خادمي للمصدر والترخيص وإشارات الحساسية قبل تخزين قرارها. الترخيص المجهول أو المصدر غير القابل للتتبع يحوّل حالة الحقوق إلى `held`، وتظل السلامة في `review` حتى قرار بشري. لا تمنح المادة المولدة أو المصدر الموثق اعتمادًا تلقائيًا؛ إنما تُحفظ ملاحظة قابلة للعرض تفسر سبب انتظار المراجعة.

تُظهر خزنة الحقوق وطابور المراجعة هذه الملاحظة، ثم يستبدل قرار المراجع بها ملاحظة اعتماد أو تجميد أو رفض. يحفظ هذا المسار سبب القرار دون كشف أسرار أو محاولة تقييم ادعائي لمحتوى لم يُفحص.
