# تقييم تكاملات الذكاء والبحث المصرح بها لـNOVA

## النتيجة

يعتمد NOVA حاليًا على مزود النموذج المدمج في المشروع لإخراج خطط منظمة فقط، بينما تتعامل المسارات الحتمية مع أوامر الحالة والمراجعة والنشر والذاكرة والـPlaybooks من قاعدة بيانات XDAW NOVA مباشرةً. هذا هو المسار التشغيلي الوحيد النشط للذكاء داخل البرنامج.

## تقييم الموصلات المتاحة

كانت موصلات **Google Gemini** و**OpenAI** و**Perplexity** و**Tavily** معروضة في إعدادات الجلسة لكنها غير مفعّلة. لم تُفعّل، ولم يُطلب أو يُسجل أي مفتاح API أو جلسة متصفح أو بيانات وصول.

> لا يدّعي NOVA اتصالًا شاملاً بـGPT أو Gemini أو Perplexity أو أي موقع خارجي. أي تكامل مستقبلي يحتاج موصلًا رسميًا مفوضًا ومفتاحًا أو OAuth يقدمه المالك، ثم يمر عبر طبقة خادمية مالك-مقيدة وسجل تدقيق وقيود المصدر والحقوق.

## القرار الهندسي

لا يلزم تفعيل أي موصل إضافي الآن. يُفضّل استخدام المصادر المعتمدة الموثقة ومراقب الإتاحة القائم، ثم إدخال أي نتائج إلى قاعدة المعرفة بالمراجعة الصريحة بدل الاستيراد التلقائي أو التصفح غير المقيد.
