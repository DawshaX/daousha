# حواجز إيقاع النشر الدوري

لا يسمح محرك XDAW NOVA بالنشر غير المحدود. تُحفظ حدود النشر في سياسة حساب المالك، وتُطبق داخل الحارس المركزي قبل الرفع اليدوي أو الدوري إلى YouTube.

| الحارس | الحد القابل للضبط | السلوك عند المخالفة |
|---|---|---|
| الفاصل الأدنى | 10–1440 دقيقة | يمنع الرفع ويُسجل سبب الحظر |
| السقف اليومي | 1–144 نشرًا عامًا خلال آخر 24 ساعة | يمنع نشرًا عامًا جديدًا |
| مفتاح الإيقاف | مفعّل/غير مفعّل | يوقف أي رفع جديد فورًا |
| المعاينة والحقوق والسلامة | حالات إلزامية | يوقف المهمة ويحولها للمراجعة عند الحاجة |

تُعرض الحدود في «سياسة النشر المستقل» داخل الإعدادات، ويؤدي الحارس الدوري عند فشل أي شرط إلى تسجيل تشغيل محجوب وإيقاف الجدولة في حالة `needs_approval` بدل المحاولة المتكررة.

## التحقق

تغطي الاختبارات حاليًا بلوغ السقف اليومي، والفاصل الأدنى قبل محاولة جديدة، ومفتاح الإيقاف، واشتراط المعاينة، وحدود الإدخال الخادمية (`10–1440` دقيقة و`1–144` نشرًا). وأكدت معاينة الإعدادات أن حقول «أقصر فاصل» و«السقف اليومي» ظاهرة ضمن سياسة النشر المستقل.
