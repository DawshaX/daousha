# معمل المشاهد الأصلية

يعمل معمل المشاهد في الاستوديو على النسخ التشغيلية فقط، ولا يقبل الفكرة الأم كوجهة إنتاج. يرسل وصف المشهد إلى مولد صورة أصلي، ثم يسجل النتيجة مادةً في بوابة الحقوق والسلامة قبل أن تصبح متاحة لأي خطوة لاحقة.

| الحارس | السلوك |
|---|---|
| اختيار المشروع | قائمة نسخ تشغيلية فقط |
| أنواع المخرجات | مشهد رئيسي أو مادة B-roll أو غلاف؛ كلّها أصول صور أصلية |
| وصف المشهد | ينبه إلى منع الشعارات والشخصيات الحقيقية والعناصر المملوكة للغير |
| بعد التوليد | إنشاء مادة مع تقييم حقوق/سلامة وإشعار للمراجعة |
| النشر | لا يوجد إرسال تلقائي من المعمل |
| فشل المولد | لا يُنشأ أصل ولا إشعار مراجعة مضلل |

أكد الاختبار أن الواجهة تستخدم قائمة المشاريع التشغيلية وتعرض حدود الملكية والنشر، كما تحققت معاينة الاستوديو من وضوح الحواجز.

الواجهة تعرض الآن نوع المخرج بوضوح قبل الإرسال: **مشهد رئيسي** أو **مادة B-roll** أو **غلاف**. تحققت هذه الخيارات في المعاينة على سطح المكتب والهاتف؛ وتظل كل المخرجات أصول صور تخضع لبوابة الحقوق والسلامة والمراجعة ذاتها.
