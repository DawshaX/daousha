# المراجعة والجدولة المحكومتان

لا يتحول أي مشروع إلى نشر بسبب ظهوره في الاستوديو أو قبول مادته. تفصل XDAW NOVA بين المراجعة البشرية، والتفويض الرسمي، والجدولة، وقرار الرفع.

| المرحلة | الشرط | النتيجة عند غياب الشرط |
|---|---|---|
| مراجعة المادة | قرار الحقوق والسلامة البشري | تبقى المادة معلقة أو تُحجب |
| اعتماد المشروع | فيديو مرتبط ومعتمد وإقرار معاينة | رفض انتقال الاعتماد |
| مسودة الجدولة | نسخة تشغيلية + YouTube مفوض | رفض إنشاء المسودة |
| تفعيل الجدولة | قناة YouTube رسمية وحواجز النشر | لا يبدأ أي تشغيل غير موثق |
| تشغيل الدورة | الحقوق والسلامة والمعاينة والسقف | `needs_approval` أو `failed` مع سجل وإشعار |

تعرض واجهة المراجعة النسخ التشغيلية فقط، وتوضح أن الاعتماد لا ينشر ولا يربط حسابًا. وتعرض واجهة الجدولة YouTube المفوض فقط، بينما تبقى بقية المنصات خارج النشر الدوري حتى يكتمل تفويضها الرسمي.
